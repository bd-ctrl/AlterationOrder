* คือข้อมูลที่บังคับต้องกรอก ถ้าไม่มี * แปลว่าไม่บังคับ
ข้อมูลลูกค้า
  • เบอร์โทรศัพท์ *กรอกแล้วออกจากช่อง ระบบค้นหาลูกค้าเก่าอัตโนมัติ ถ้าเจอจะเติมชื่อ/ชื่อเล่น/อีเมลให้เอง
  • ชื่อลูกค้า *กรอกเองได้ หรือปล่อยให้ระบบเติมให้จากเบอร์โทร
  • ชื่อเล่น / อีเมล / เพศไม่บังคับกรอก
  • ปุ่มถังขยะ / บันทึกร่าง / ลูกศรถัดไปล้างข้อมูลหน้านี้ทั้งหมด / เก็บข้อมูลไว้ก่อนยังไม่ส่งเข้าระบบ / ไปหน้าถัดไป
สินค้า
  • รหัสสินค้าพิมพ์หรือกดปุ่มสแกนข้างช่องเพื่อสแกนบาร์โค้ด/QR ระบบจะแยก Size และประเภทสินค้าให้อัตโนมัติ
  • ประเภทสินค้า / Size / สาขาเปลี่ยนเองได้ตามจริง
  • ชื่อพนักงานที่ติดต่อขึ้นเฉพาะกรณีสาขาของสินค้าชิ้นนั้นต่างจากสาขาที่เลือกไว้ในเฮดเดอร์
  • แก้ไขขนาดสินค้า / ไม่แก้ไขขนาดสินค้ามุมขวาบนของ “รายละเอียด” เปิด-ปิดทั้งชุดวัดตัวของสินค้าชิ้นนั้น
  • แก้ไข / ไม่แก้ไขของแต่ละจุดวัดตัว ต้องกด “แก้ไข” ก่อนถึงจะลากปรับค่าตัวเลขหรือสไลเดอร์ได้
  • แนบรูป / ถังขยะเล็ก / เพิ่มสินค้าแนบรูปสินค้า (ไม่บังคับ) / ลบสินค้าชิ้นนั้น / เพิ่มสินค้าอีกชิ้นในบิลเดียวกัน
นัดรับสินค้า
  • สถานะการชำระเงินจ่ายแล้ว / ค้างชำระ — เลือกค้างชำระจะมีช่องกรอกจำนวนเงินที่ค้างขึ้นมา
  • สาขาที่นัดรับ *เลือก Messenger หรือขนส่งเอกชนจะมีช่อง “สถานที่ส่ง” ให้กรอกเพิ่ม
  • วันที่นัดรับ * / เวลานัดรับถ้าเป็นวันนี้หรือพรุ่งนี้ จะขึ้นคำว่า “งานด่วน” สีแดงให้เห็นชัด
  • บันทึกข้อมูลปุ่มสีเข้ม บันทึกจริงและส่งเข้า Lark ทันที
ใช้ได้ทุกหน้า
  • บันทึกร่างเก็บข้อมูลทั้งหมดไว้ในเครื่องนี้ก่อน ยังไม่ส่งเข้าระบบ — กลับมาดูหรือทำต่อได้ที่ปุ่ม “ประวัติ” แท็บ “ร่างที่บันทึกไว้”
  • ประวัติดูใบสั่งแก้ที่เคยบันทึกไว้ทั้งหมดของสาขาที่เลือก สามารถสแกนคิวอาร์โค้ดเลขงาน (เลขที่บิล) ในช่องค้นหาได้ ระบบจะแสดงรายละเอียดของงานนั้นตาม Product ID และ Suitcube Order ให้ทันที
