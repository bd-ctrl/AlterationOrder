* คือข้อมูลที่บังคับต้องกรอก ถ้าไม่มี * แปลว่าไม่บังคับ
แถบด้านบน (เห็นได้ทุกหน้า)
  • สาขา Dropdownกดแล้วเลือกสาขาจากรายการ
  • พนักงานขาย พิมพ์แล้วเลือกชื่อพิมพ์ชื่อ ระบบจะขึ้นรายชื่อให้เลือกด้านล่าง
  • เลขที่บิลขึ้นให้อัตโนมัติ ไม่ต้องกรอกเอง
ข้อมูลลูกค้า
  • เบอร์โทรศัพท์ * พิมพ์ตัวเลขกรอกแล้วออกจากช่อง ระบบค้นหาลูกค้าเก่าอัตโนมัติ ถ้าเจอจะเติมชื่อ/ชื่อเล่น/อีเมลให้เอง
  • ชื่อ / นามสกุล * พิมพ์ข้อความแยกช่องชื่อ-นามสกุล ตรงกับ Salesforce — กรอกเองได้ หรือปล่อยให้ระบบเติมให้จากเบอร์โทร
  • ชื่อเล่น / อีเมล พิมพ์ข้อความไม่บังคับกรอก
  • เพศ ปุ่มเลือก 1 ใน 3หญิง / ชาย / ไม่ระบุ — กดปุ่มเพื่อสลับ
  • ปุ่มถังขยะ / บันทึกร่าง / ลูกศรถัดไปล้างข้อมูลหน้านี้ทั้งหมด / เก็บข้อมูลไว้ก่อนยังไม่ส่งเข้าระบบ / ไปหน้าถัดไป
สินค้า (ต่อสินค้า 1 ชิ้น)
  • รหัสสินค้า พิมพ์แล้ว suggest หรือกดสแกนพิมพ์รหัสจะขึ้นรายการให้เลือก หรือกดปุ่มสแกนบาร์โค้ด/QR ข้างช่อง ระบบจะแยก Size และประเภทสินค้าให้อัตโนมัติ (ตัดไซซ์ท้ายรหัสออก เหลือแต่รหัสจริง)
  • ประเภทสินค้า Dropdownปกติขึ้นให้เองจากรหัสสินค้า แต่เปลี่ยนเองได้
  • Size พิมพ์ข้อความ/ตัวเลขขึ้นให้เองจากรหัสสินค้า แก้เองได้
  • สาขา Dropdownสาขาที่สินค้าชิ้นนี้เบิกมา (ถ้าต่างจากสาขาบนแถบด้านบน ระบบจะรายงานไปที่ Salesforce ว่าเป็น “สาขาอื่นๆ”)
  • ชื่อพนักงานที่ติดต่อ พิมพ์ข้อความขึ้นเฉพาะกรณีสาขาของสินค้าชิ้นนั้นต่างจากสาขาที่เลือกไว้ในแถบด้านบน
  • หมายเหตุ พิมพ์ข้อความไม่บังคับกรอก
  • แก้ไขขนาดสินค้า / ไม่แก้ไขขนาดสินค้า ปุ่มเลือก 2 ทางมุมขวาบนของ “รายละเอียด” เปิด-ปิดทั้งชุดวัดตัวของสินค้าชิ้นนั้น
  • แก้ไข / ไม่แก้ไข ของแต่ละจุดวัดตัว ปุ่มเลือก 2 ทางต้องกด “แก้ไข” ก่อนถึงจะแก้ค่าได้
  • ช่องตัวเลขวัดตัว พิมพ์ตัวเลขตรงๆเช่น ความยาวแขน / ต้นแขน
  • สายวัด ลากสไลเดอร์เช่น อก / เอว / สะโพก — ลากซ้าย/ขวาเพื่อระบุค่าเอาเข้า/ขยายออก ตัวเลขจะขึ้นให้เองด้านบนสไลเดอร์
  • แนบรูป เลือกไฟล์รูปไม่บังคับ
  • ถังขยะเล็กลบสินค้าชิ้นนั้น (ถ้าเหลือชิ้นเดียวในบิล จะเคลียร์ข้อมูลในก้อนนั้นแทนการลบ เพราะบิลต้องมีสินค้าอย่างน้อย 1 ชิ้นเสมอ)
  • เพิ่มสินค้าเพิ่มก้อนสินค้าใหม่ในบิลเดียวกัน
นัดรับสินค้า
  • สถานะการชำระเงิน ปุ่มเลือก 2 ทางจ่ายแล้ว / ค้างชำระ — เลือกค้างชำระจะมีช่องกรอกจำนวนเงินที่ค้าง (พิมพ์ตัวเลข) ขึ้นมา
  • สาขาที่นัดรับ * Dropdownรวมตัวเลือก Messenger และขนส่งเอกชนไว้ด้วย เลือกอันใดอันหนึ่งจะมีช่อง “สถานที่ส่ง” (พิมพ์ข้อความ) ให้กรอกเพิ่ม
  • วันที่นัดรับ * ปฏิทิน (Date picker)กดแล้วเลือกวันที่จากปฏิทิน เลือกวันในอดีตไม่ได้
  • เวลานัดรับ ปุ่มเลือก 2 ทาง“ไม่ระบุ” (ค่าเริ่มต้น ไม่ต้องกรอกเวลา) / “ระบุ” (ขึ้นช่องเลือกเวลาแบบนาฬิกา)
  • งานด่วน ปุ่ม chip กดสลับระบบเดาให้อัตโนมัติจากวันที่นัดรับ (น้อยกว่า 7 วันจากวันนี้ = เดาว่า “ด่วน”) แต่กดเปลี่ยนเองได้เสมอ กดแล้วเปลี่ยนเป็นสีแดง = ด่วน
  • บันทึกข้อมูลปุ่มสีทอง มุมขวาล่าง บันทึกจริงเข้า Lark Base
แถบด้านล่าง (เห็นได้ทุกหน้า)
  • บันทึกร่างปุ่มไอคอนดินสอ เก็บข้อมูลทั้งหมดไว้ในเครื่องนี้ก่อน ยังไม่ส่งเข้าระบบ — กลับมาดูหรือทำต่อได้ที่ปุ่ม “ประวัติ” แท็บ “ร่างที่บันทึกไว้”
  • ประวัติปุ่มไอคอนนาฬิกาย้อนเวลา ดูใบสั่งแก้ที่เคยบันทึกไว้ทั้งหมดของสาขาที่เลือก มีช่องค้นหา (พิมพ์เลขที่บิล/ชื่อลูกค้า/เบอร์โทร) และปุ่มสแกนคิวอาร์โค้ดเลขงาน ระบบจะแสดงรายละเอียดของงานนั้นตาม Product ID และ Suitcube Order ให้ทันที
